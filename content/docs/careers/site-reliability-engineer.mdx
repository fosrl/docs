## About Pangolin

Pangolin delivers identity-aware remote access to internal apps and services. Our platform replaces legacy VPNs and simplifies secure access to infrastructure, applications, and developer environments.

We build in the open and are self‑hosted by default so teams retain control over data and infrastructure. The system is policy‑driven, integrates with standard IdPs, exposes clear observability and health, and provides an API for automation.

If you're interested in open-source auth and networking infrastructure, we'd love to chat.

## About The Role

As a Site Reliability Engineer at Pangolin, you'll own how we build, ship, and run the software we operate. You'll work on our CI/CD pipelines, release process, and the cloud infrastructure behind our hosted offerings, and you'll help self-hosted users get reliable installs and upgrades. As an early hire, you'll set the operational habits the team keeps for years.

## What You'll Do

- Design, build, and maintain CI/CD pipelines for the Pangolin container, Newt, Gerbil, and Olm
- Own release automation, including multi-architecture builds, image publishing, and versioned upgrades
- Build and run the cloud infrastructure for hosted environments, including networking, secrets, and access control
- Set up metrics, logs, and tracing so we can see problems before users report them
- Respond to incidents, lead postmortems, and turn repeated failures into automation
- Write installer and upgrade tooling that works for self-hosters on common Linux distributions
- Ship quickly and get instant feedback from our large open-source user-base
